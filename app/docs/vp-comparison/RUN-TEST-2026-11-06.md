## What works in the window

- **Welcome screen:** New project, a sample project, and demo "recovered changes" and "recent projects" lists (labelled as design fixtures).
- **New project:** a name creates an empty "Class diagram 1" in the workspace.
- **Menu:** File, Edit, View, Tools and Navigate submenus. Ctrl+K opens command search.
- **Disabled controls give reasons**, for example "Not available yet: adding classes needs the project model" and "SVG export is planned for v0.1".
- **Sample project:** Customer and Order with a "places" association (1 and 0..*).
  - Selecting a class shows its name, attributes and operations in the inspector.
  - Renaming a class updates the model list, the relationship name ("Client places Order") and every diagram showing it.
  - A second diagram, "Order details", shows the same Order model.
  - The relationship inspector edits name, role and multiplicity at each end.
  - A bad multiplicity such as `abc` shows a written error and keeps focus; `1..*` is accepted.

## What does not work yet

- Class, Association, Note, Arrange, Pan, New diagram, Save, Export, Undo and Redo are disabled.
- Dragging a class does nothing. Undo stays disabled after a rename, so the window is not using the core history yet.
- There is no way back to the welcome screen. File only offers Save, Export and New diagram, so the app must be restarted.
- Add attribute, Add operation, Appearance (this view only) and Advanced do nothing. Advanced says its fields "arrive with the project model".
- Open project is disabled. Recent projects are fixtures. Nothing is saved ("Prototype · nothing is saved").

## Limits of this test
